👨‍💻 About Me

Hey! I’m Kakashi.

I’m a developer who started by experimenting with Discord bots and gradually turned those experiments into larger projects involving backend systems, APIs, dashboards, music infrastructure, automation, and community tools.

I enjoy building things from scratch, learning how systems work behind the scenes, and constantly improving old projects instead of leaving them behind.

Most of my development journey has been around the Discord ecosystem, but I’m also interested in web development, servers, APIs, databases, infrastructure, and anything that lets me build something useful.

I don’t just want to use technology — I want to understand how it works and build my own version of it.

🚀 What I’m Currently Building

🎵 Ongaku

Ongaku is my modern Discord music ecosystem.

It started as a music bot and has grown into a much larger project involving music playback, Lavalink infrastructure, web services, monitoring, Discord UI, and companion features.

🔥 Ongaku Features

* 🎵 High-quality Discord music playback
* ⚡ Lavalink-based audio infrastructure
* 🔄 Multiple Lavalink nodes
* 🖥️ Live server/node monitoring
* 🎛️ Interactive Discord player controls
* 📃 Queue management
* 🔀 Shuffle & repeat controls
* 🎚️ Volume controls
* 🎶 Lyrics system
* 📚 Playlist support
* 🌐 Web dashboard & services
* 📡 API-based monitoring
* 🛡️ Infrastructure designed for reliability
* 🔗 Ongaku Companion ecosystem
* 🎨 Custom Discord UI & emoji system

🧩 Ongaku Stack

Discord.js
      │
      ▼
   Kazagumo
      │
      ▼
   Shoukaku
      │
      ▼
   Lavalink
      │
      ├── Ongaku Main
      │
      └── Ongaku Backbone

Ongaku is one of the projects I’m most interested in expanding into a complete ecosystem rather than keeping it as “just another music bot.”

🤖 KAKASHI

KAKASHI is my Discord bot ecosystem and one of my longest-running projects.

The goal isn’t simply to make another bot with hundreds of commands.

KAKASHI is designed to become a community-focused Discord platform with moderation, utility, automation, support systems, temporary voice channels, verification, AI features, dashboards, and integrations.

🧠 KAKASHI Features

* 🛡️ Moderation
* 🎫 Ticket System
* 🤖 AI-powered Ticket Assistant
* 🔊 Temporary Voice Channels
* 🎙️ Voice Verification
* ⚙️ Server Automation
* 🎮 Fun & Community Features
* 🧰 Utility Commands
* 🌐 Dashboard
* 🌍 Multilingual Support
* 🔗 Ongaku Integration
* 💳 Premium Features & Entitlements

🧠 KAKASHI AI

I’m also working on an AI-powered ticket/support system that can learn server-specific knowledge while keeping usage controlled through different plans.

The idea is to make support systems smarter without turning every Discord server into a generic AI chatbot.
